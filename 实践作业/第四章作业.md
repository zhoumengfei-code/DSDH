## 一、实验做了什么

一句话：**把 800 首诗变成 800 个词向量，看两位诗人各自"最舍得用"的是哪些词。**

流程三步，每步一个脚本：

```
① download_corpus.py   下载《全唐诗》JSON（公有领域，chinese-poetry 项目整理）
② prepare_corpus.py    筛李白杜甫 → 繁转简 → 去残句 → 各等距抽 400 首，一首一文件
③ tfidf_compare.py     分词去噪 → TF-IDF → Top20 / 差异词 → 4 张图 + 4 张表
```

一键复现：`bash run_all.sh`

## 二、语料

|       | 李白              | 杜甫              |
| ----- | --------------- | --------------- |
| 全集收录  | 1207 首          | 1489 首          |
| 清洗后可用 | 1201 首          | 1488 首          |
| 抽样入语料 | 400 首 / 35583 字 | 400 首 / 32791 字 |

- 来源：[chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)《全唐诗》，公有领域。
- **等距抽样**而不是取前 400 首：避免语料只落在某一创作时期。
- 原文是繁体，先转简体再分词——jieba 词典是简体的，"雲""騎"不转会切成生词。
- 文档粒度：**一首诗 = 一篇文档**，共 800 篇，远超题面"各不少于 10 篇"。

## 三、方法

### 3.1 分词与去噪（三层过滤）

| 层    | 做法                            | 拦掉的例子       |
| ---- | ----------------------------- | ----------- |
| 清洗   | 正则只保留汉字                       | 《》、〔1〕、数字   |
| 词性过滤 | 去掉 u助词/p介词/c连词/r代词/m数词/q量词 等  | 之、而、也、我、千   |
| 停用词表 | 自建 `src/stopwords.txt`（古汉语场景） | 不、无、今日、不知、君 |

单字取舍：**只放行名词性单字**——"月、山、江、舟"是意象词，留；"见、来、去"是泛动词，去。

### 3.2 TF-IDF

```python
TfidfVectorizer(
    analyzer=lambda x: x,   # 输入已是分好的词
    min_df=3,               # 至少在 3 篇里出现，去孤例
    max_df=0.5,             # 过半文档都有的词太泛，丢
    sublinear_tf=True,      # tf 取 1+log(tf)，压住刷屏的高频词
    norm="l2",              # 每篇向量归一化，长短诗才可比
)
```

两个关键点：

1. **idf 在全部 800 篇上统一计算**，不是两位诗人各算各的。只有这样，"明月"的权重才由"两人是不是都用"决定——这是对比成立的前提。
2. 每位诗人取 400 篇向量的**均值**作为"用词画像"，再排序取 Top 20。单首诗平均只有 26 个词，不求平均的话，排名会被一两首诗带跑。

过滤后词表 1473 个词。语料 3.5 万字/人的量级下，Top 20 是稳的，20 名之后不必当真。

### 4.3 怎么读这组数字

- **两人共有的"客、水、山、风"**：说明底色相同——都是行旅中的诗人，这是共同背景，不是差异。
- **李白侧的酒、玉、黄金、明月、仙人、桃李**：宴饮、仙道、明丽物象，浪漫飘逸的一面落在了词上。
- **杜甫侧的病、杖、白头、干戈、舟、江湖**：老病、战乱、漂泊，沉郁写实的一面同样落在了词上。

## 五、差异能说明什么、不能说明什么（解读，约 200 字）

**能说明的，是用词分布的差异。** 在等量 400 首的语料里，李白每万字用"酒"27 次、"黄金"23 次、"明月"14 次、"仙人"13 次、"妾"20 次；杜甫对应只有 13、4、2、0、0 次。反过来，"病"杜甫 19 次、李白 2 次，"杖"17 对 0，"干戈"11 对 0，"白头"10 对 1。这组数字指向题材重心的不同：李白多宴饮、仙道、明丽物象与闺情，杜甫多老病、战乱、舟行与漂泊。两人共有的"客""水""山"则说明底色相同——都是行旅中的诗人。

**不能说明的，是诗好不好。** 词频只数词，不数词怎么用：句法、用典、语气、结构一概看不见，"酒"出现得多，不等于写酒写得深。也不能据此下完整的风格判断——只抽了 400 首，繁简转换、分词粒度和停用词表都会挪动榜尾的名次（"水""山""客"就是两人拉锯的词）。所以它给的是**用词倾向的证据**，不是诗艺裁判。

## 八、局限与注意

1. **词云字号不可跨图比**：两张词云各自内部归一化，要比大小看 `fig3` 或 csv。
2. **榜尾不稳**：3.5 万字/人的语料量，Top 10 稳，20 名开外受停用词表选择影响明显（"石""气""吴"就属于这类边缘词）。
3. **方法只到"词"为止**：TF-IDF 看不见句法、修辞、用典，结论只能覆盖用词倾向。
4. **停用词表是人为选择**：换一套表，结果会在榜尾浮动。写报告时要承认这一点。
5. macOS 中文字体写死在 `FONT_CANDIDATES`（Hiragino Sans GB），换 Windows/Linux 要改，否则图里中文变方框。
